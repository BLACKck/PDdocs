# 飞书知识库查询 Skill

## 功能定位

专门用于查询、读取和分析飞书知识库（KAKA 知识）中的项目文档、需求文档等内容。

## 核心能力

### 1. 知识库文档读取
- 读取飞书知识库中的所有项目文档
- 获取项目的详细需求文档
- 读取流程图、产品结构图等配套文档
- 支持读取子文档和嵌套文档

### 2. 知识库搜索
- 根据关键词搜索知识库文档
- 按项目名称筛选文档
- 按文档类型（需求、流程图、原型等）筛选
- 支持模糊搜索和精确搜索

### 3. 文档结构分析
- 分析知识库文档的整体结构
- 提取需求文档的章节结构
- 识别共同的文档模式
- 生成文档结构报告

### 4. 内容提取
- 从需求文档中提取模板结构
- 提取撰写规范和最佳实践
- 生成融合版模板和规范
- 提取项目经验和教训

## API 调用示例

### 获取知识库节点

```python
from feishu_api_client import FeishuClient

# 初始化客户端
client = FeishuClient(APP_ID, APP_SECRET, TENANT_KEY)

# 获取 access_token
if client.get_access_token():
    # 获取知识库节点
    wiki_nodes = client.get_wiki_nodes(KNOWLEDGE_SPACE_ID)
    
    # 遍历节点
    for node in wiki_nodes:
        print(f"项目名称：{node.get('title')}")
        print(f"Token: {node.get('node_token')}")
        print(f"是否有子文档：{node.get('has_child')}")
```

### 获取子文档

```python
# 获取项目的子文档
if node.get('has_child'):
    child_nodes = client.get_child_nodes(node.get('node_token'))
    for child in child_nodes:
        print(f"子文档：{child.get('title')}")
```

### 获取文档内容

```python
# 获取文档的详细内容
document_content = client.get_document_content(document_token)
```

## 常见问题

### Q1: 如何确认知识库访问权限？
A: 检查应用机器人是否在知识库所在群组中，并确认有足够的访问权限。

### Q2: 如何处理 API 调用失败？
A: 检查网络连接、access_token 是否有效、API 配置是否正确。

### Q3: 如何处理大量文档？
A: 分批处理，先获取文档列表，再逐步获取详细内容。

### Q4: 如何验证查询结果？
A: 对比本地文档或请求用户确认查询结果的准确性。
