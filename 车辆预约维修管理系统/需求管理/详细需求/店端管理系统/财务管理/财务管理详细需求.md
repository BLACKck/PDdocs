# 财务管理详细需求

## 1. 功能描述
管理维修费用和财务数据，包括维修账单生成、费用统计、财务报表等。

## 2. 详细需求
- 维修账单生成
- 费用统计和分析
- 财务报表生成
- 收支管理

## 3. 字段定义
| 字段名称 | 字段类型 | 字段取值逻辑 |
|---------|---------|------------|
| 账单ID | 字符串 | 系统生成 |
| 预约ID | 字符串 | 系统关联 |
| 客户ID | 字符串 | 系统关联 |
| 车辆ID | 字符串 | 系统关联 |
| 维修项目 | 文本 | 输入维修项目 |
| 配件费用 | 数字 | 输入配件费用 |
| 工时费用 | 数字 | 输入工时费用 |
| 总费用 | 数字 | 配件费用 + 工时费用 |
| 支付状态 | 枚举 | 待支付、已支付、部分支付 |
| 支付方式 | 字符串 | 现金、微信支付、支付宝支付、银行卡支付 |
| 账单日期 | 日期 | 系统自动生成 |

## 4. 筛选字段
| 筛选字段 | 筛选类型 | 筛选操作逻辑 |
|---------|---------|------------|
| 账单日期 | 日期范围 | 选择日期范围进行筛选 |
| 客户姓名 | 模糊匹配 | 输入客户姓名进行搜索 |
| 支付状态 | 下拉选择 | 选择支付状态进行筛选 |
| 金额范围 | 数字范围 | 输入金额范围进行筛选 |

## 5. 操作逻辑
| 操作按钮 | 操作逻辑 | 成功提示 | 错误提示 |
|---------|---------|---------|----------|
| 生成账单 | 根据维修项目和配件生成账单 | 账单生成成功 | 生成失败 |
| 编辑账单 | 修改账单信息 | 编辑成功 | 编辑失败 |
| 删除账单 | 删除账单信息 | 删除成功 | 删除失败 |
| 标记支付 | 标记账单为已支付 | 标记成功 | 标记失败 |
| 生成报表 | 生成财务报表 | 报表生成成功 | 生成失败 |

## 6. 状态流转
```
维修完成 → 生成账单 → 待支付 → 已支付/部分支付
```

## 7. 数据权限
| 角色 | 权限限制 |
|------|----------|
| 系统管理员 | 可访问和修改所有财务数据 |
| 门店管理员 | 可访问和修改本门店的财务数据 |
| 维修人员 | 可查看账单信息，不可修改 |
