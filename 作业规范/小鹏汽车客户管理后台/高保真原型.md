# 小鹏汽车客户管理后台高保真原型设计

## 1. 设计规范

### 1.1 颜色方案
- 主色调：#0066CC（小鹏蓝）
- 辅助色：#E6F0FA（浅蓝）、#FF6600（橙色）
- 中性色：#F5F5F5（背景色）、#333333（文字色）、#666666（次要文字色）
- 状态色：#52C41A（成功）、#FAAD14（警告）、#F5222D（错误）

### 1.2 字体方案
- 主字体：微软雅黑
- 标题字体大小：18px、16px
- 正文字体大小：14px、12px
- 按钮字体大小：14px

### 1.3 组件规范
- 按钮：圆角4px，高度32px
- 输入框：圆角4px，高度32px
- 表格：行高36px，表头背景色#F5F5F5
- 卡片：圆角8px，阴影效果
- 图标：使用Material Design图标

### 2.3 客户线索管理页面

![客户线索管理页面](https://via.placeholder.com/1200x800?text=客户线索管理页面)

**功能点**：
- 筛选条件（状态、来源、车型、时间范围、跟进人）：支持多条件组合筛选，筛选条件可折叠
- 线索列表（客户姓名、电话、意向车型、来源、状态、创建时间、跟进人）：支持列排序，状态显示不同颜色
- 操作按钮（新增、编辑、删除、跟进、转化）：悬停显示操作提示
- 批量操作功能：支持批量删除、批量分配
- 分页控件：显示总条数，支持跳转页码

**交互细节**：
- 点击新增按钮弹出表单模态框
- 点击编辑按钮弹出编辑表单模态框
- 点击删除按钮弹出确认对话框
- 点击跟进按钮弹出跟进记录表单
- 点击转化按钮弹出转化为商机表单
- 支持表格行内编辑部分字段
- 支持线索导入/导出功能
