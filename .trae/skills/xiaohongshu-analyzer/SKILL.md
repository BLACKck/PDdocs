# 小红书数据分析

## 功能描述

此技能用于分析小红书平台上的帖子和评论数据，具体功能包括：

1. **登录小红书**：访问并登录小红书网页版
2. **搜索功能**：根据关键词搜索相关帖子
3. **帖子筛选**：根据发布时间排序，选择有评论的帖子
4. **评论提取**：从帖子中提取评论者的ID、昵称、评论内容和时间
5. **兴趣分析**：分析评论者对特定话题的兴趣程度
6. **数据整理**：将分析结果整理为结构化数据

## 适用场景

当用户需要：
- 了解特定话题在小红书上的讨论情况
- 分析用户对某个产品或服务的态度
- 收集小红书平台上的用户评论数据
- 研究特定话题的用户兴趣分布

## 使用方法

1. **指定关键词**：提供需要搜索的关键词（如"小鹏P7 价格"）
2. **设置筛选条件**：可选择按发布时间排序，优先选择有评论的帖子
3. **分析评论**：提取评论信息并分析用户兴趣
4. **获取结果**：接收整理好的结构化数据

## 输出格式

技能会输出包含以下内容的结构化数据：

- 帖子信息：ID、标题、内容
- 评论数据：评论者ID、昵称、评论内容、评论时间
- 兴趣分析：每个评论者对话题的兴趣程度和分析原因

## 示例使用

**输入**："分析小红书上关于'小鹏P7 价格'的帖子和评论"

**输出**：
```json
{
  "post": {
    "id": "帖子ID",
    "title": "帖子标题",
    "content": "帖子内容"
  },
  "comments": [
    {
      "id": "评论者ID",
      "name": "评论者昵称",
      "content": "评论内容",
      "time": "评论时间",
      "interested": true/false,
      "reason": "兴趣分析原因"
    }
  ]
}
```

## 注意事项

- 确保网络连接稳定，以便访问小红书平台
- 搜索结果可能受平台限制，部分内容可能无法访问
- 评论提取的数量可能受页面加载限制
- 兴趣分析基于评论内容的语义理解，可能存在一定主观性
