## 2. 项目背景

### 2.1 项目概述
贪吃蛇是一款经典的休闲益智游戏，起源于1976年的街机游戏《Blockade》。游戏玩法简单但富有挑战性：玩家控制一条蛇在屏幕上移动，通过吃食物来增长蛇身，同时避免撞墙或撞到自己。本项目旨在开发一个现代化的网页版贪吃蛇游戏，提供良好的用户体验和视觉效果。

### 2.2 项目目标
- 开发一个功能完善、操作流畅的贪吃蛇游戏
- 提供良好的用户体验和视觉效果
- 实现经典游戏玩法，同时加入现代化元素
- 支持多种难度级别，满足不同玩家需求
- 记录玩家成绩，增加游戏可玩性

### 2.3 项目范围
- **前端界面**：游戏画面、控制按钮、分数显示、游戏状态提示
- **游戏逻辑**：蛇的移动、食物生成、碰撞检测、计分系统
- **数据存储**：本地存储最高分数、游戏设置
- **交互设计**：键盘控制、游戏暂停/继续、重新开始

## 3. 用户调研

### 3.1 目标用户群体

#### 3.1.1 主要用户群体
| 用户群体 | 特征描述 | 使用场景 | 核心需求 |
|----------|----------|----------|----------|
| 休闲玩家 | 工作间隙寻求放松，游戏时间碎片化 | 午休、通勤、等待时 | 简单易上手，随时可玩 |
| 怀旧玩家 | 对经典游戏有情怀，追求复古体验 | 空闲时间娱乐 | 经典玩法，操作流畅 |
| 挑战玩家 | 追求高分，喜欢挑战自我 | 专注游戏时间 | 难度递增，成绩记录 |
| 学生群体 | 课余时间娱乐，喜欢竞技 | 课间、放学后 | 排行榜，社交分享 |

#### 3.1.2 用户画像

**用户画像 1：休闲玩家 - 小李**
- **年龄**：28岁
- **职业**：办公室职员
- **游戏习惯**：每天午休时玩15-20分钟
- **痛点**：现有游戏广告多、加载慢、操作复杂
- **需求**：快速开始、无广告、简单操作

**用户画像 2：怀旧玩家 - 老王**
- **年龄**：35岁
- **职业**：程序员
- **游戏习惯**：周末休闲时玩，追求经典体验
- **痛点**：现代游戏过于复杂，找不到纯粹的游戏乐趣
- **需求**：经典玩法、复古风格、流畅体验

**用户画像 3：挑战玩家 - 阿强**
- **年龄**：22岁
- **职业**：大学生
- **游戏习惯**：每天挑战高分，追求排名
- **痛点**：游戏难度不够，缺乏挑战性
- **需求**：多种难度、成绩记录、排行榜

### 3.3 用户痛点分析

#### 3.3.1 现有产品痛点
1. **广告干扰**：大多数免费游戏广告过多，影响体验
2. **加载缓慢**：部分网页游戏加载时间长
3. **功能单一**：缺乏难度选择和成绩记录
4. **操作不便**：移动端和PC端适配不佳
5. **视觉陈旧**：界面设计 outdated

| 需求 | 优先级 | 说明 |

| 经典玩法还原 | P0 | 保留核心玩法 |
| 无广告干扰 | P0 | 纯净游戏体验 |
| 多种难度选择 | P1 | 满足不同水平玩家 |
| 成绩记录功能 | P1 | 记录最高分数 |

## 4. 需求分析

### 4.1 功能需求

#### 4.1.1 核心功能（P0 - Must Have）

**1. 游戏核心机制**
- 蛇的移动控制（上下左右）
- 食物生成和吃掉逻辑
- 蛇身增长机制
- 碰撞检测（墙壁、自身）
- 游戏结束判定

**2. 用户界面**
- 游戏画布显示
- 当前分数显示
- 最高分数显示
- 游戏状态提示（开始、暂停、结束）

**3. 游戏控制**
- 键盘方向键控制
- 游戏开始/重新开始
- 游戏暂停/继续

#### 4.1.2 扩展功能（P1 - Should Have）

**1. 难度系统**
- 简单模式（速度慢）
- 普通模式（标准速度）
- 困难模式（速度快）

**2. 数据持久化**
- 本地存储最高分数
- 本地存储游戏设置

**3. 响应式设计**
- 适配桌面浏览器
- 适配移动设备（触摸屏控制）

#### 4.1.3 增值功能（P2 - Could Have）

**1. 排行榜**
- 本地排行榜
- 分数提交

**2. 主题皮肤**
- 多种颜色主题
- 经典/现代风格切换

### 4.2 非功能需求

#### 4.2.1 性能需求
- 游戏帧率 ≥ 30 FPS
- 响应延迟 < 50ms
- 页面加载时间 < 3秒

#### 4.2.2 兼容性需求
- 支持 Chrome、Firefox、Safari、Edge 最新两个版本
- 支持 iOS Safari 和 Android Chrome

#### 4.2.3 可用性需求
- 无需注册即可游戏
- 即开即玩，无需下载
- 操作简单，学习成本低

## 5. 用户故事

### 5.1 核心功能用户故事

#### US-001：开始游戏
```
作为 一名玩家
我想要 点击开始按钮就能立即开始游戏
以便于 快速进入游戏状态

验收标准：
- Given 玩家在游戏首页
- When 点击"开始游戏"按钮
- Then 游戏立即开始，蛇出现在画布中央，食物随机生成
```

#### US-002：控制蛇移动
```
作为 一名玩家
我想要 使用键盘方向键控制蛇的移动方向
以便于 操控蛇去吃食物

验收标准：
- Given 游戏进行中
- When 按下方向键（上/下/左/右）
- Then 蛇按照对应方向移动，不能立即反向移动
```

#### US-003：吃食物增长
```
作为 一名玩家
我想要 蛇吃到食物后身体变长
以便于 获得分数并增加游戏难度

验收标准：
- Given 游戏进行中
- When 蛇头触碰到食物
- Then 蛇身增加一节，分数增加，新食物随机生成
```

#### US-004：碰撞检测
```
作为 一名玩家
我想要 当蛇撞墙或撞到自己时游戏结束
以便于 增加游戏挑战性

验收标准：
- Given 游戏进行中
- When 蛇头撞到墙壁或蛇身
- Then 游戏结束，显示最终分数和"游戏结束"提示
```

#### US-005：暂停游戏
```
作为 一名玩家
我想要 在游戏过程中可以暂停
以便于 处理临时事务

验收标准：
- Given 游戏进行中
- When 按下空格键或点击暂停按钮
- Then 游戏暂停，显示"暂停"提示
- When 再次按下空格键或点击继续按钮
- Then 游戏继续
```

### 5.2 扩展功能用户故事

#### US-006：选择难度
```
作为 一名玩家
我想要 选择不同的游戏难度
以便于 根据自己的水平选择合适的挑战

验收标准：
- Given 玩家在游戏首页
- When 选择难度（简单/普通/困难）
- Then 游戏以对应速度开始
```

#### US-007：查看最高分数
```
作为 一名玩家
我想要 查看自己的最高分数记录
以便于 挑战自我，争取更高分

验收标准：
- Given 玩家在游戏首页或游戏结束页
- Then 显示本地存储的最高分数
- When 当前分数超过最高分数
- Then 更新最高分数并提示"新纪录"
```

## 8. 调研结论

### 8.1 核心需求确认
根据调研分析，贪吃蛇游戏的核心需求包括：

1. **流畅的游戏体验**：使用 Canvas 渲染，确保 30+ FPS
2. **经典玩法还原**：保留核心机制，操作简单直观
3. **无广告干扰**：提供纯净的游戏环境
4. **难度选择**：简单/普通/困难三种模式
5. **成绩记录**：本地存储最高分数
6. **响应式设计**：适配桌面和移动设备

### 8.2 功能范围建议

**第一阶段（MVP）**：
- 核心游戏机制（移动、吃食物、碰撞检测）
- 基础 UI（分数显示、游戏状态）
- 键盘控制
- 暂停/继续功能

**第二阶段**：
- 难度选择
- 最高分数记录
- 移动端适配

**第三阶段**：
- 排行榜
- 主题皮肤
