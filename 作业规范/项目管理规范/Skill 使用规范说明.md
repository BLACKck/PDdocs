# Skill 使用规范说明

## 1. 背景

为了提升产品经理相关工作的标准化和专业性，创建了 7 个产品经理系列 Skill，并规范各智能体如何调用这些 Skill 进行作业。

## 2. Skill 与智能体的关系

### 2.1 定位差异
- **智能体（Agent）**：是执行者，负责思考、决策和跨智能体协作
- **Skill**：是工具包，提供标准化的专业能力和作业方法

### 2.2 协作模式
```
智能体（思考 + 决策 + 协作）
    ↓ 调用
Skill（专业能力 + 标准化方法）
    ↓ 输出
符合规范的产出物
```

## 3. 产品经理 Skill 体系

已创建 7 个产品经理相关 Skill：

| Skill 名称 | 核心能力 | 触发场景 |
|-----------|---------|---------|
| 需求分析 | 需求调研、用户故事、优先级评估 | 需求调研、用户故事编写 |
| 需求文档 | PRD、MRD 撰写（遵循作业规范） | 需求文档撰写 |
| 流程图设计 | 业务流程图、用户旅程图、状态图 | 流程图绘制 |
| 原型设计 | 低保真/高保真原型、交互设计 | 原型设计 |
| 竞品分析 | 竞品调研、SWOT 分析、差异化策略 | 竞品分析 |
| 数据分析 | 指标设计、数据分析、A/B 测试 | 数据分析 |
| 产品规划 | 产品战略、路线图、商业模式 | 产品规划 |

## 4. 智能体 Skill 调用规范

### 4.1 ProductExpert（产品专家）

**必须调用的 Skill：**
- 需求调研任务 → 【需求分析 Skill】
- 需求文档撰写 → 【需求文档 Skill】
- 流程图设计 → 【流程图设计 Skill】（或与 ProcessExpert 协作）
- 原型设计 → 【原型设计 Skill】（或与 DesignExpert 协作）
- 竞品分析 → 【竞品分析 Skill】
- 数据分析 → 【数据分析 Skill】
- 产品规划 → 【产品规划 Skill】

**职责：**
- 根据任务类型正确调用 Skill
- 确保产出物符合 Skill 定义的规范
- 与 ProcessExpert、DesignExpert 协作完成相关工作

### 4.2 ProcessExpert（流程专家）

**必须调用的 Skill：**
- 流程图绘制 → 【流程图设计 Skill】

**职责：**
- 调用【流程图设计 Skill】进行专业流程图绘制
- 与 ProductExpert 协作理解业务需求
- 与 DesignExpert 协作确保流程图与原型一致
- 确保流程图符合 Skill 定义的规范

### 4.3 DesignExpert（设计专家）

**应调用的 Skill：**
- 原型设计 → 【原型设计 Skill】

**职责：**
- 调用【原型设计 Skill】进行专业原型设计
- 与 ProductExpert、ProcessExpert 协作
- 确保原型符合 Skill 定义的规范

### 4.4 其他智能体

其他开发、测试、版本控制等智能体暂时不需要调用产品经理 Skill，按原有规范执行。

## 5. Skill 调用时机

### 5.1 调用原则
- 智能体在执行任务时，**应优先调用**相应的 Skill
- Skill 提供标准化的作业方法和输出规范
- 确保所有产出物符合 Skill 定义的规范

### 5.2 调用流程
1. 智能体接收任务
2. 判断任务类型
3. 调用对应的 Skill
4. 按照 Skill 规范执行任务
5. 产出符合规范的交付物

## 6. 监督与检查

### 6.1 项目管理专家职责
- 监督 ProductExpert 是否正确调用 Skill
- 监督 ProcessExpert 是否调用流程图设计 Skill
- 监督 DesignExpert 是否调用原型设计 Skill
- 检查各智能体的产出物是否符合 Skill 规范
- 对于未正确使用 Skill 的智能体，及时提醒和指导
- 记录 Skill 使用情况，评估使用效果

### 6.2 质量专家职责
- **Skill 调用检查**：检查各智能体是否正确调用了相应的 Skill
- **Skill 规范符合性检查**：检查产出物是否符合 Skill 定义的规范
- 输出 Skill 调用检查报告
- 输出 Skill 规范符合性检查报告

## 8. 使用示例

### 示例 1：ProductExpert 撰写需求文档

```
任务：为"宠宝贝"项目撰写需求文档

ProductExpert 执行流程：
1. 接收任务
2. 调用【需求文档 Skill】
3. 按照 Skill 规范：
   - 创建项目文件夹结构
   - 撰写需求调研文档
   - 撰写需求分析文档
   - 绘制产品结构图
   - 撰写需求文档主文档
   - 撰写详细需求文档（按模块）
4. 通知知识库同步专家
5. 通知质量专家检查
```

### 示例 2：ProcessExpert 绘制流程图

```
任务：为"宠宝贝"项目绘制业务流程图

ProcessExpert 执行流程：
1. 接收任务
2. 调用【流程图设计 Skill】
3. 按照 Skill 规范：
   - 理解业务需求和流程
   - 选择流程图类型（业务流程图/用户旅程图/状态图）
   - 使用标准符号绘制
   - 遵循布局和颜色规范
4. 与 ProductExpert、DesignExpert 确认
5. 输出流程图文件
```

### 示例 3：DesignExpert 设计原型

```
任务：为"宠宝贝"项目设计高保真原型

DesignExpert 执行流程：
1. 接收任务
2. 调用【原型设计 Skill】
3. 按照 Skill 规范：
   - 理解需求文档
   - 设计页面结构和交互
   - 设计组件和状态
   - 遵循设计规范和适配规范
4. 与 ProductExpert、ProcessExpert 确认
5. 输出原型文件
```

## 9. 常见问题

### Q1: 智能体可以不调用 Skill 吗？
**A**: 不建议。Skill 提供了标准化的作业方法和规范，不调用 Skill 可能导致产出物不符合规范要求。

### Q2: 多个智能体可以调用同一个 Skill 吗？
**A**: 可以。例如 ProductExpert 和 ProcessExpert 都可以调用【流程图设计 Skill】，但职责不同。

### Q3: Skill 会替代智能体吗？
**A**: 不会。Skill 是工具，智能体是使用者。智能体负责思考、决策和协作，Skill 提供专业能力支持。

### Q4: 如何检查 Skill 是否正确调用？
**A**: 质量专家会进行 Skill 调用检查和规范符合性检查，项目管理专家会监督 Skill 使用情况。
