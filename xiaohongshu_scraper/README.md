# 小红书数据抓取工具

## 功能介绍

本工具用于从小红书抓取指定关键词的帖子和评论数据，并分析用户对该关键词的兴趣程度。

## 功能特点

- 自动登录小红书
- 搜索指定关键词（默认：岑村揽胜）
- 按发布时间倒序排序
- 抓取有评论的帖子
- 提取评论者信息（昵称、评论内容、评论时间）
- 分析用户对关键词的兴趣程度
- 导出数据为Excel表格

## 环境要求

- Python 3.7+
- Google Chrome 浏览器
- 依赖库：
  - selenium
  - webdriver-manager
  - pandas
  - openpyxl
  - requests
  - beautifulsoup4
  - lxml
  - python-dotenv
  - json5

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

1. **配置Chrome路径**
   - 打开 `scraper.py` 文件
   - 修改第14行的 `CHROME_PATH` 为您的Chrome浏览器安装路径

2. **运行脚本**
   ```bash
   python scraper.py
   ```

3. **登录小红书**
   - 脚本会自动打开Chrome浏览器并访问小红书
   - 请在浏览器中完成登录（扫码或账号密码登录）
   - 登录成功后，在命令行按Enter键继续

4. **数据抓取**
   - 脚本会自动搜索"岑村揽胜"相关帖子
   - 按发布时间倒序排序
   - 抓取有评论的帖子及其评论数据

5. **查看结果**
   - 数据会导出为 `xiaohongshu_data.xlsx` 文件
   - 包含以下字段：
     - 帖子ID
     - 帖子标题
     - 帖子内容
     - 评论者ID
     - 评论者昵称
     - 评论内容
     - 评论时间
     - 是否感兴趣
     - 思考原因

## 自定义设置

- **修改关键词**：在 `run()` 方法中修改 `keyword` 参数
- **修改抓取数量**：在 `run()` 方法中修改 `max_posts` 参数
- **修改导出文件名**：在 `export_to_excel()` 方法中修改 `filename` 参数

## 注意事项

1. **登录问题**：小红书可能会要求验证码或滑块验证，请手动完成
2. **反爬措施**：频繁抓取可能会触发小红书的反爬机制，建议适当调整抓取速度
3. **数据准确性**：由于小红书页面结构可能会变化，抓取功能可能需要定期更新
4. **合规性**：请确保您的使用符合小红书的服务条款

## 故障排除

- **Chrome驱动问题**：如果遇到驱动问题，请确保Chrome浏览器版本与驱动版本匹配
- **登录失败**：如果登录失败，请检查网络连接并手动尝试登录
- **抓取失败**：如果抓取失败，可能是页面结构变化，请更新CSS选择器
