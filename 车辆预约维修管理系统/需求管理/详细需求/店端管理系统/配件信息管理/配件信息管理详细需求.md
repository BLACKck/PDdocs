# 配件信息管理详细需求

## 1. 功能描述
管理维修配件信息，记录配件名称、型号、库存数量、价格等，支持配件信息的添加、编辑、删除和查询。

## 2. 详细需求
- 记录配件名称、型号、库存数量、价格等
- 支持配件信息的添加、编辑、删除和查询
- 支持库存预警和库存盘点

## 3. 字段定义
| 字段名称 | 字段类型 | 字段取值逻辑 |
|---------|---------|------------|
| 配件ID | 字符串 | 系统生成 |
| 配件名称 | 字符串 | 输入配件名称 |
| 型号 | 字符串 | 输入配件型号 |
| 库存数量 | 数字 | 输入库存数量 |
| 单价 | 数字 | 输入配件单价 |
| 供应商 | 字符串 | 输入供应商名称 |
| 库存预警值 | 数字 | 输入库存预警值 |

## 4. 筛选字段
| 筛选字段 | 筛选类型 | 筛选操作逻辑 |
|---------|---------|------------|
| 配件名称 | 模糊匹配 | 输入配件名称进行搜索 |
| 型号 | 模糊匹配 | 输入型号进行搜索 |
| 库存状态 | 下拉选择 | 选择库存状态进行筛选（正常、预警、缺货） |

## 5. 操作逻辑
| 操作按钮 | 操作逻辑 | 成功提示 | 错误提示 |
|---------|---------|---------|----------|
| 添加配件 | 添加配件信息 | 添加成功 | 添加失败 |
| 编辑配件 | 修改配件信息 | 编辑成功 | 编辑失败 |
| 删除配件 | 删除配件信息 | 删除成功 | 删除失败 |
| 查询 | 根据筛选条件查询配件信息 | 查询成功 | 查询失败 |
| 库存盘点 | 盘点配件库存 | 盘点成功 | 盘点失败 |

## 6. 状态流转
```
配件列表 → 添加/编辑/删除配件 → 配件列表
库存管理 → 库存预警 → 采购申请
```

## 7. 数据权限
| 角色 | 权限限制 |
|------|----------|
| 系统管理员 | 可访问和修改所有配件信息 |
| 门店管理员 | 可访问和修改本门店的配件信息 |
| 维修人员 | 可查看配件信息，不可修改 |
