## 5. 状态流转结构

```mermaid
stateDiagram-v2
    [*] --> 准备中: 页面加载
    准备中 --> 进行中: 开始游戏
    进行中 --> 暂停: 暂停
    暂停 --> 进行中: 继续
    进行中 --> 结束: 碰撞
    结束 --> 准备中: 返回菜单
    结束 --> 进行中: 重新开始
    
    state 准备中 {
        [*] --> 显示开始界面
        显示开始界面 --> 等待用户操作
        等待用户操作 --> [*]
    }
    
    state 进行中 {
        [*] --> 游戏循环
        游戏循环 --> 更新位置
        更新位置 --> 检测碰撞
        检测碰撞 --> 渲染画面
        渲染画面 --> 游戏循环
        检测碰撞 --> 结束: 碰撞发生
    }
    
    state 暂停 {
        [*] --> 停止循环
        停止循环 --> 显示暂停提示
    }
    
    state 结束 {
        [*] --> 停止循环
        停止循环 --> 保存分数
        保存分数 --> 显示结束界面
    }
```
