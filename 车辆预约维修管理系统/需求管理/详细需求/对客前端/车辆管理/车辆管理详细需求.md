# 车辆管理详细需求

## 1. 功能描述
客户添加和管理车辆信息，支持添加多辆车辆，记录车辆基本信息、行驶里程、保险信息等，支持车辆信息的编辑和删除。

## 2. 详细需求
- 支持添加多辆车辆
- 记录车辆基本信息、行驶里程、保险信息等
- 支持车辆信息的编辑和删除

## 3. 字段定义
| 字段名称 | 字段类型 | 字段取值逻辑 |
|---------|---------|------------|
| 车牌号 | 字符串 | 符合车牌号格式 |
| VIN码 | 字符串 | 17位字母数字组合 |
| 品牌 | 字符串 | 选择或输入 |
| 型号 | 字符串 | 选择或输入 |
| 购买日期 | 日期 | 选择日期 |
| 行驶里程 | 数字 | 大于等于0 |
| 保险到期日 | 日期 | 选择日期 |

## 4. 筛选字段
| 筛选字段 | 筛选类型 | 筛选操作逻辑 |
|---------|---------|------------|
| 车牌号 | 模糊匹配 | 输入车牌号进行搜索 |
| 品牌 | 下拉选择 | 选择品牌进行筛选 |

## 5. 操作逻辑
| 操作按钮 | 操作逻辑 | 成功提示 | 错误提示 |
|---------|---------|---------|----------|
| 添加车辆 | 验证车辆信息，添加到系统 | 添加成功 | 信息填写不完整/格式不正确 |
| 编辑车辆 | 修改车辆信息，保存到系统 | 编辑成功 | 信息填写不完整/格式不正确 |
| 删除车辆 | 删除车辆信息 | 删除成功 | 删除失败 |

## 6. 状态流转
```
未添加车辆 → 添加车辆 → 车辆列表 → 编辑/删除车辆
```

## 7. 数据权限
| 角色 | 权限限制 |
|------|----------|
| 客户 | 只能管理自己的车辆信息 |
