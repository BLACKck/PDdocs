## 2. 模块概述

### 2.1 模块名称
用户界面模块（User Interface Module）

### 2.2 模块定位
用户界面模块负责游戏的视觉呈现和用户交互，包括游戏画布渲染、分数显示、控制按钮、游戏状态提示等。该模块直接影响用户体验，是玩家与游戏交互的桥梁。

### 2.3 模块目标
- 提供清晰美观的游戏界面
- 实现流畅的游戏画面渲染
- 提供直观的用户操作方式
- 实时显示游戏状态和分数
- 支持响应式布局，适配不同设备

## 3. 功能需求

### 3.1 游戏画布

#### 3.1.1 功能描述
使用HTML5 Canvas绘制游戏画面，包括蛇、食物、背景等游戏元素。

#### 3.1.2 详细需求
- 画布大小：400x400像素
- 网格系统：20x20网格，每格20x20像素
- 背景色：#1a1a2e（深色背景）
- 蛇身颜色：#4CAF50（绿色）
- 蛇头颜色：#66BB6A（亮绿色）
- 食物颜色：#F44336（红色）
- 边框：2px实线，颜色#333

#### 3.1.3 需求优先级
**P0（Must Have）** - 核心界面，必须实现

#### 3.1.4 用户故事
```
作为 一名玩家
我想要 在游戏画布上看到蛇和食物
以便于 了解游戏状态并操控游戏

验收标准：
- Given 游戏进行中
- Then 我能在画布上看到蛇和食物
- And 蛇移动时画面流畅更新
```

#### 3.1.5 字段定义

| 字段名称 | 字段类型 | 字段取值逻辑 | 验证规则 |
|---------|---------|-------------|----------|
| canvasWidth | Number | 画布宽度（像素） | 默认400 |
| canvasHeight | Number | 画布高度（像素） | 默认400 |
| gridSize | Number | 网格大小（像素） | 默认20 |
| backgroundColor | String | 画布背景色 | 默认'#1a1a2e' |
| snakeColor | String | 蛇身颜色 | 默认'#4CAF50' |
| snakeHeadColor | String | 蛇头颜色 | 默认'#66BB6A' |
| foodColor | String | 食物颜色 | 默认'#F44336' |

#### 3.1.6 渲染逻辑

| 元素 | 渲染逻辑 | 更新频率 |
|------|---------|---------|
| 背景 | 每帧清空画布并填充背景色 | 每帧 |
| 蛇身 | 遍历snakeBody数组，绘制每个网格 | 每帧 |
| 蛇头 | 绘制第一个元素，使用不同颜色 | 每帧 |
| 食物 | 在foodPosition位置绘制圆形 | 每帧 |
| 网格线 | 可选，绘制辅助网格线 | 初始化 |

#### 3.1.7 渲染算法

```javascript
function render() {
    // 清空画布
    ctx.fillStyle = backgroundColor;
    ctx.fillRect(0, 0, canvasWidth, canvasHeight);
    
    // 绘制蛇
    snakeBody.forEach((segment, index) => {
        const x = segment.x * gridSize;
        const y = segment.y * gridSize;
        
        if (index === 0) {
            // 蛇头
            ctx.fillStyle = snakeHeadColor;
        } else {
            // 蛇身
            ctx.fillStyle = snakeColor;
        }
        
        ctx.fillRect(x, y, gridSize - 1, gridSize - 1);
    });
    
    // 绘制食物
    const foodX = foodPosition.x * gridSize + gridSize / 2;
    const foodY = foodPosition.y * gridSize + gridSize / 2;
    ctx.fillStyle = foodColor;
    ctx.beginPath();
    ctx.arc(foodX, foodY, gridSize / 2 - 2, 0, Math.PI * 2);
    ctx.fill();
}
```

### 3.2 分数显示

#### 3.2.1 功能描述
在游戏界面实时显示当前分数和最高分数。

#### 3.2.2 详细需求
- 显示当前分数：大号字体，醒目位置
- 显示最高分数：小号字体，当前分数下方
- 分数更新时实时刷新
- 使用清晰的字体和颜色

#### 3.2.3 需求优先级
**P0（Must Have）** - 核心功能，必须实现

#### 3.2.4 用户故事
```
作为 一名玩家
我想要 看到当前分数和最高分数
以便于 了解游戏进度和挑战目标

验收标准：
- Given 游戏进行中
- Then 我能在界面上看到当前分数
- And 能看到历史最高分数
- When 分数变化时
- Then 显示实时更新
```

#### 3.2.5 字段定义

| 字段名称 | 字段类型 | 字段取值逻辑 | 验证规则 |
|---------|---------|-------------|----------|
| currentScore | Number | 当前游戏分数 | 整数，≥0 |
| highScore | Number | 历史最高分数 | 整数，≥0，从localStorage读取 |
| scoreFontSize | String | 分数字体大小 | 默认'32px' |
| highScoreFontSize | String | 最高分字体大小 | 默认'16px' |

#### 3.2.6 显示布局

```

│                             │
│        分数: 120            │  ← 当前分数（32px，白色）

│    │                  │     │
│    └──────────────────┘     │
│                             │

```

### 3.3 控制按钮

#### 3.3.1 功能描述
提供开始、暂停、重新开始等游戏控制按钮。

#### 3.3.2 详细需求
- 开始游戏按钮：游戏准备或结束时显示
- 暂停/继续按钮：游戏进行中显示
- 重新开始按钮：游戏结束时显示
- 按钮样式统一，有悬停效果
- 按钮状态根据游戏状态动态变化

#### 3.3.3 需求优先级
**P0（Must Have）** - 核心功能，必须实现

#### 3.3.4 用户故事
```
作为 一名玩家
我想要 通过按钮控制游戏
以便于 开始、暂停或重新开始游戏

验收标准：
- Given 游戏准备中
- Then 能看到开始游戏按钮
- When 点击开始
- Then 游戏开始，按钮变为暂停
- When 点击暂停
- Then 游戏暂停，按钮变为继续
```

#### 3.3.5 按钮状态表

| 游戏状态 | 显示按钮 | 按钮功能 |
|---------|---------|---------|
| ready（准备中） | 开始游戏 | 开始游戏 |
| playing（进行中） | 暂停 | 暂停游戏 |
| paused（暂停中） | 继续 | 继续游戏 |
| over（结束） | 重新开始 | 重新开始游戏 |

#### 3.3.6 按钮样式

| 属性 | 取值 |
|------|------|
| 宽度 | 120px |
| 高度 | 40px |
| 背景色 | #4CAF50 |
| 文字颜色 | #FFFFFF |
| 字体大小 | 16px |
| 圆角 | 4px |
| 悬停背景色 | #45a049 |
| 禁用状态背景色 | #cccccc |

### 3.7 响应式布局

#### 3.7.1 功能描述
界面适配不同屏幕尺寸，确保在桌面和移动设备上都有良好的显示效果。

#### 3.7.2 详细需求
- 桌面端：画布居中，侧边显示操作说明
- 移动端：画布自适应宽度，操作说明在下方
- 画布最大宽度不超过屏幕宽度
- 保持画布比例1:1

#### 3.7.3 需求优先级
**P1（Should Have）** - 重要功能，建议实现

#### 3.7.4 响应式断点

| 断点 | 屏幕宽度 | 布局调整 |
|------|---------|---------|
| 桌面端 | ≥768px | 画布400x400，侧边栏显示信息 |
| 平板端 | 480px-767px | 画布自适应，最大400px |
| 移动端 | <480px | 画布自适应宽度，信息在下方 |

## 4. 非功能需求

### 4.1 性能需求
- 渲染帧率≥30 FPS
- 界面响应延迟<100ms
- 动画流畅，无卡顿

### 4.2 兼容性需求
- 支持Chrome、Firefox、Safari、Edge等主流浏览器
- 支持移动端浏览器
- 支持键盘和触摸操作

### 4.3 可访问性需求
- 按钮有明确的焦点状态
- 支持键盘导航
- 颜色对比度符合WCAG标准

## 6. 接口定义

### 6.1 对外接口

| 接口名称 | 参数 | 返回值 | 说明 |
|---------|------|--------|------|
| render() | 无 | void | 渲染游戏画面 |
| updateScore(score) | score: Number | void | 更新分数显示 |
| showGameState(state) | state: String | void | 显示游戏状态提示 |
| hideGameState() | 无 | void | 隐藏游戏状态提示 |
| setButtonState(state) | state: String | void | 设置按钮状态 |
| showDifficultySelector() | 无 | void | 显示难度选择器 |
| hideDifficultySelector() | 无 | void | 隐藏难度选择器 |

### 6.2 事件监听

| 事件名称 | 触发条件 | 处理逻辑 |
|---------|---------|---------|
| clickStart | 点击开始按钮 | 调用gameCore.startGame() |
| clickPause | 点击暂停按钮 | 调用gameCore.pauseGame() |
| clickResume | 点击继续按钮 | 调用gameCore.resumeGame() |
| clickRestart | 点击重新开始按钮 | 调用gameCore.restartGame() |
| changeDifficulty | 改变难度选择 | 更新selectedDifficulty |
| keydown | 按下键盘 | 处理方向键和空格键 |
