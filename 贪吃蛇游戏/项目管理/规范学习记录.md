## 3. 常见问题预防措施

### 3.1 文件位置错误预防
- **项目根目录**: `d:\PDM\PDdocs\贪吃蛇游戏\`
- **禁止**在作业规范文件夹下创建项目文件
- 所有项目文件必须放在正确的项目目录下

### 3.2 需求文档组织混乱预防
- ProductExpert 必须严格按照模块化结构创建需求文档
- 在【详细需求】下为每个模块创建独立文件夹
- 每个模块的需求文档包含完整的字段定义、操作逻辑、状态流转和数据权限

### 3.3 原型设计规范预防
- DesignExpert 必须为所有模态框添加 `max-height: 80vh` 和 `overflow-y: auto`
- 确保滚动功能正常
- 统一所有页面的模态框样式

### 3.4 流程执行问题预防
- 建立严格的协作流程顺序
- 每个智能体完成后再通知下一个智能体开始工作
- 加强质量检查环节

### 3.5 GitHub 同步问题预防
- 确保所有文件夹都包含实际文件
- 对于需要跟踪的空文件夹添加 `.gitkeep` 文件
- 定期执行 `git status` 检查文件状态

### 3.6 命令执行问题预防
- 使用简单的提交信息，避免特殊字符（如冒号、空格）
- 分步骤执行 git 命令
- 使用 PowerShell 原生命令

### 3.7 Skill 使用规范预防
- ProductExpert 正确调用需求分析、需求文档、流程图设计、原型设计等 Skill
- ProcessExpert 调用流程图设计 Skill 进行流程图绘制
- DesignExpert 调用原型设计 Skill 进行原型设计
